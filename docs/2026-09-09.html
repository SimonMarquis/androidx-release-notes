API Changes

  • Adds support to specify the style of individual parts of a compound composable (such as TextField or DatePicker) directly in the style parameter of the composable. This enables, for example, creating a TextField-like composable that allows customizing each of the decorator boxes using a style, enabling them to be overridden at a theme level or at the call site. I43c0f
  • Material 2 text field overloads that accept value, onValueChange parameters are deprecated. Please migrate to the overload that uses TextFieldState to hoist its state. I6b841 b/556234973
  • Removed @ExperimentalFoundationApi annotation from undoState in TextFieldState. I93a44
  • Add default configuration objects for each lazy layout containing the default values used in the corresponding @Composeable functions. Currently only contains the default cache window for each layout. I58633
  • Flag isUsingDynamicDefaultCacheWindowIn[List|Grid|StaggeredGrid]s when enabled will cause lazy layouts to use a cache window that uses the average size of visible items to prefetch ahead of the viewport with a minimum ahead window of 10% of the viewport and a maximum ahead window of 50% of the viewport. I59212
  • Deprecated LazyListPrefetchStrategy, LazyListPrefetchScope, and LazyListPrefetchResultScope. Prefetching behavior should be configured using LazyLayoutCacheWindow on LazyColumn or LazyRow. LazyLayoutCacheWindow provides a declarative, viewport-based caching mechanism that automatically prepares items ahead of and keeps items behind the visible window without requiring complex imperative scheduling callbacks. The new API is simpler and requires less configuration steps than LazyListPrefetchStrategy. I1fa2d
  • Adds PolygonShape.transformed and PolygonShape.scaledToFit extension functions in Compose Foundation for transforming and fitting polygon shapes. I3f327
  • This change refactors the Styles API into two independent pieces: the Styles DSL and the modifiers that are configured by the DSL. The previous Style-based implementation is still present but will be deprecated and removed. Any uses of it should be replaced with the new CommonStyle based API.
  • Key components introduced:
    • CustomStyle & CommonStyle: Base interfaces and merging helpers for declaring composable styles.
    • StyleResolver: Resolves style properties in composition and binds to layout nodes via Modifier.styleResolver.
    • Modifier scopes: Modifier.appearance, Modifier.placement, and dynamic callback-based Modifier.padding and Modifier.graphicsLayer.
    • Property primitives: stylePropertyOf, styleLocalOf.
    • Types useful for style properties: Breadth, Fill, and Shadows.
  • The new modifiers are useful for implementing a design system using the Styles API but are not required. A design system may use these modifiers or provide its own. Ieb8cc b/549921960

  • Introduces MorphPolygonShape in Compose Foundation for morphing animations between polygon shapes, along with toPolygonShape() converters for RoundedCornerShape and CutCornerShape. Ic5a89
  • Introduces PolygonShape in Compose Foundation for rendering regular, star, and custom rounded polygons with corner smoothing. I0b99d

Security

1.0.0

Major features of 1.0.0:

  • UpdateInfoService Framework: Base service enabling OEM OTA clients and update services to declare and broadcast available security update metadata.
  • Available Security Patch Level (ASPL): Standardizes reporting the newest available patch level across system and subsystem updates to on-device consumers.
  • Kotlin & Java Compatibility: Provides UpdateInfoService for Kotlin Coroutines (fetchUpdates()) and ListenableFutureUpdateInfoService for Java clients using Guava ListenableFuture (fetchUpdatesAsync()).
  • Extensible Provider Configuration: Includes configurable caching, rate-limiting, and error-handling hooks.

Security

1.1.0

Major features of 1.1.0

  • Unified Security State Querying (SecurityPatchState): Provides a unified programmatic view of on-device security patch levels across the system, system modules (Mainline), and kernel.
  • Pending Update Discovery (queryAllAvailableUpdates() & fetchAvailableSecurityPatchLevel()): Aggregates data from registered on-device update providers to discover pending security updates across system components.
  • Granular Vulnerability Verification (areCvesPatched()): Checks whether specific CVEs have been resolved on the device, including evaluating vendor supplemental patch records.
  • Update Readiness Assessment (isDeviceFullyUpdated()): Provides high-level checks to evaluate whether a device has installed all available security patches.
  • Vulnerability Reporting (createVulnerabilityReportUrl()): Generates standardized URLs for security bulletins and CVE details.
  • Kotlin & Java Compatibility: Complete asynchronous support via Kotlin Coroutines / Flow and Java ListenableFuture APIs.
