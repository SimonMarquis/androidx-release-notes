Emoji2

1.7.0-alpha01

** Performance Release **

This release is a major performance improvement over prior relases.

• Reduced memory footprint: Metadata trie RAM usage is reduced from ~2.2 MB to ~80 KB.
• Reduced startup overhead: Startup object allocations are reduced from 24,178 to 82.
• Allocation-free text scanning: Scanning standard Latin text now performs zero allocations.
• Reduced latency: Median Latin text scan latency is reduced by up to 83% (from 16.43 µs to 2.66 µs).
• Automatic bypass on API 35+: EmojiCompat processing is automatically bypassed on devices with system-updatable fonts.

API Changes

  • Added setUseAfterUpdatableSystemFonts to EmojiCompat.Config to optionally continue using EmojiCompat on Android 15 (API 35) and above even when updatable system fonts are available on all devices. The default value will disable EmojiCompat on API35+ saving memory and text processing latency. I7235e b/541363642

Bug Fixes

  • Emoji2 picker - Updated Compose compileSdk to API 37. This means that a minimum AGP version of 9.2.0 is required when using Compose. Id45cd b/413674743

  • NavHost now provides an overload that accepts predictivePopEnterTransition and predictivePopExitTransition parameters to allow for custom transition during the predictive back gesture.
